## 2.3.4.3.1 末端移动规划算法（基于 MoveIt 2）

### 概述

为应对新赛季对矿流程复杂但目标点明确的特点，我们成功开发并集成了基于 MoveIt 2 框架的自动化运动规划与控制模块。该模块的核心目标是以智能软件决策**完全取代传统手动操作**，通过上位机实现机械臂末端轨迹的自动化规划与精确执行。

具体而言，MoveIt 2 现已能够：
- **自动规划最优路径**：依据任务需求，智能计算从当前位姿到指定目标点的最优运动方案
- **多自由度运动控制**：同步实现末端平移、旋转以及复合约束下的运动（平面约束、方向约束、姿态约束等）
- **完整的关节解算**：通过雅可比伪逆和自适应阻尼算法，实时求解各关节所需的位置、速度和加速度
- **平稳精确执行**：驱动机械臂以 50 Hz 高频闭环控制，平稳、稳定、准确地完成全自动移动任务

通过这一集成方案，显著提升了作业效率和流程一致性，为新赛季的复杂矿流程提供了可靠的自动化基础。

### 系统架构（五模式实时控制框架）

为满足不同作业场景的约束需求，系统采用**五模式实时控制框架**，每个模式对应不同的末端运动约束与自由度组合。核心引擎基于**雅可比伪逆（自适应阻尼最小二乘法）**，在 20 ms 控制周期内实时求解末端运动对应的关节控制量，同时内置多层安全防护（死区、限幅、限位预防），确保机械臂的平稳与安全运动。

**五个控制模式：**
1. **NO 模式**：控制值直接透传，机械臂不受 NUC 约束
2. **UP 模式**：末端在垂直于 `e_hat` 方向（link6 y 轴）的平面内运动，末端姿态完全锁定
3. **TURN 模式**：末端在垂直于 `normal_direction` 的平面内运动，允许绕 z 轴旋转
4. **ROLL 模式**：末端在垂直于 `e_hat` 方向的平面内运动，允许绕 `e_hat` 轴旋转
5. **RESET 模式**：使用 MoveIt 2 规划轨迹自动归位到默认位置 `[0, 2.65, -0.86, 3.14, 3.14, 0]`

**控制流程：**
- 每个约束模式（UP/TURN/ROLL）都基于同一个 `direction_constraint()` 函数，该函数实现了完整的雅可比伪逆步进控制
- 模式切换时自动记录切换瞬间的末端位置和控制器 EE 位置，作为后续相对位移的参考
- 第一帧模式切换后跳过约束计算（防止切换跳变），从第二帧开始应用约束

### 方案选型与理由
- **核心方法**：雅可比伪逆（自适应阻尼最小二乘）+ 实时步进控制
- **约束处理**：平面约束通过方向投影实现；末端姿态通过四元数误差和角速度限幅实现；关节约束通过等比缩放预防
- **多模式架构**：NO/UP/TURN/ROLL/RESET 五模态，分别对应不同的约束和应用场景
- **理由**：
  - 实时性高（20ms 周期，可达 50 Hz）
  - 约束形式灵活（平面、方向、姿态自由度组合）
  - 安全性有保证（阻尼、死区、限幅、限位预防一应俱全）
  - 代码成熟且已在实机验证

### 核心算法框架

**direction_constraint() 函数**是所有约束模式的统一求解引擎，核心思想为：

1. **相对位移驱动 + 约束平面投影**
   - 计算控制器相对位移（相对于模式切换时刻）投影到约束平面
   - 自动消除约束方向分量，确保末端运动始终在允许平面内
   - 内置漂移修正（反馈增益 2.0）防止数值误差累积

2. **自适应阻尼最小二乘伪逆（DLS）**
   - SVD 条件数评估 → 自适应阻尼系数（$\lambda \in [0.005, 0.1]$）
   - 线性插值映射条件数 [50, 200] 到阻尼范围，平衡精度与鲁棒性
   - $J^{\dagger} = J^T(JJ^T + \lambda^2 I)^{-1}$ 确保奇异点附近不发散

3. **灵活的姿态控制模式**
   - **UP**（完全锁定）：末端姿态固定在参考方向，高精度应用场景
   - **ROLL**（z 轴自由）：允许绕约束方向旋转，适合旋转操作
   - **TURN**（完全自由）：不约束姿态，最大自由度

4. **多层安全约束**
   - 死区（0.5mm 位置 + 0.01rad 朝向）防止抖动
   - 单周期最大步长 0.1 rad 硬限幅
   - 关节边界软限位（±0.05 rad 裕度）等比缩放保证不越界
   - 速度限幅 0.45 m/s

5. **零空间关节同步**
   - 零空间投影处理次级任务：机械臂与控制器角度融合
   - 增益 0.3 rad/s，无额外计算开销，不干扰主任务

### 关键参数与设计选择

| 设计要素 | 数值 | 设计思想 |
|--------|------|--------|
| **控制周期** | 20 ms | 50 Hz 实时闭环，满足高频约束控制 |
| **约束容差** | 0.03 m | 模式切换时的冲击缓冲，防止控制突变 |
| **漂移修正** | 增益 2.0 | 数值误差自动反馈修正，数个周期内消除累积 |
| **阻尼范围** | [0.005, 0.1] | 条件数 50→200 时线性映射，奇异点附近自动减速 |
| **位置/朝向死区** | 0.5mm / 0.01rad | 消除抖动，提升稳定性 |
| **单步最大关节变化** | 0.1 rad | 防止快速跳跃，保护实机安全 |
| **关节软限位裕度** | ±0.05 rad | 提前保护，避免硬限位碰撞 |
| **零空间同步增益** | 0.3 rad/s | 低速对齐，无额外负担 |
| **最大末端速度** | 0.45 m/s | 精确控制与安全的平衡点 |

### 代码架构与技术亮点

**统一控制引擎**
- 所有约束模式（UP/TURN/ROLL）共享同一个 `direction_constraint()` 函数
- 通过参数化选择约束方向、姿态锁定策略，灵活应对多种场景
- 内置完整的鲁棒性处理（漂移修正、阻尼自适应、多层安全约束）

**五模式实时框架**
- 模式切换自动记录参考位置与相对位移原点，消除切换跳变
- 每个模式的处理函数通过简单参数变换调用统一引擎，代码复用率高
- RESET 模式独立使用 MoveIt 离线规划，适应归位等长遥程任务

**可靠性设计**
- 相对位移驱动 + 反馈漂移修正：消除数值累积误差
- 条件数自适应阻尼：在保留精度的情况下自动躲避奇异点
- 分层约束（死区→速度→步长→限位）：多级防护避免异常发生

### 性能指标与验证要点

**核心指标**
- 约束方向漂移（< 5mm），位置跟踪 RMS（< 20mm），姿态误差（< 5°）
- 模式切换平滑性（无跳变），关节边界容纳率（100% 无越限）
- 奇异点处理（条件数升高自动减速，不发散）

**测试覆盖**
- 五种模式的单独与组合切换验证
- 速度、加速度边界条件（死区、限幅）
- 关节边界附近的软限位有效性
- 长时间运行的数值稳定性

### 关键风险与缓解方案

| 风险 | 缓解方案 | 预期效果 |
|------|--------|--------|
| 数值误差在约束平面积累 | 漂移修正反馈（增益 2.0） | 自动消除，无人工干预 |
| 奇异点附近解不稳定 | SVD 条件数自适应阻尼 | 自动增大阻尼，光滑过渡 |
| 关节快速突跳伤害实机 | 单步硬限幅 0.1 rad + 软限位 | 双重保护，无越界 |
| 模式切换产生控制跳跃 | 相对位移驱动 + 第一帧跳过约束 | 平滑过渡，无抖动 |
| 恒定增益关节同步影响主任务 | 零空间投影隔离 | 并行优化，互不干扰 |
